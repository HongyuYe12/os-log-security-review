# AI-Based Threat Detection in Operating-System Logs

A literature-review project examining how machine learning and deep learning can support anomaly and threat detection in operating-system logs.

The cleaned report discusses:

- why raw operating-system logs require parsing and structuring;
- limitations of manual and rule-based detection;
- PCA, SVM, decision trees, neural networks, RNN/GRU, LSTM, and Transformer approaches;
- adaptability, scalability, data quality, and interpretability research gaps;
- future directions including explainable AI and continuous learning.
